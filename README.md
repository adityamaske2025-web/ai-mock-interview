# AI Mock Interview Platform

A full-stack AI-powered mock interview platform built using the MERN stack.

## Features

* User Authentication (JWT)
* Create Mock Interviews
* Dynamic Interview Questions
* Interview Timer
* Auto Submit
* Result Page with Score
* Feedback System
* PDF Report Download
* MongoDB Database
* Responsive Dashboard
* Deployed on Vercel & Render

## Tech Stack

### Frontend

* React
* Vite
* Tailwind CSS
* Axios
* React Router

### Backend

* Node.js
* Express.js
* MongoDB Atlas
* JWT Authentication

## Installation

### Backend

```bash
cd server
npm install
npm run dev
```

### Frontend

```bash
cd client
npm install
npm run dev
```

## Project Workflow

1. Register/Login
2. Create Interview
3. Answer Questions
4. Submit Interview
5. View Result
6. Download PDF Report
